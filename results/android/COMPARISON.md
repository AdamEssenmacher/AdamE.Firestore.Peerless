# Android: peered vs Peerless (generated)

Generated by `scripts/compare-android.py` from 6 runs. Every cell is a median over all callbacks of that case in all runs of that mode. Wall and CPU span the whole path each mode has: peered from entry into the .NET listener; Peerless from entry into the Java listener (so it includes encoding). Both end with the snapshot fully converted into the same .NET value model.
